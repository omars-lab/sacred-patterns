When authoring Tier 1 entries that place MULTIPLE lenses on the same construction circle (each lens anchored via its own `intersect Xn C0 CL_n` + paired `connect arc` declarations), bikar's face-walker treats each lens INDEPENDENTLY. Each lens's declared C0-arc is the only C0 region enrolled into that lens's boundary; neighboring C0 sub-arcs between lenses (or between a lens and a polygon vertex) stay DORMANT. The shared inscribed polygon stays whole. Each lens emits as a distinct face with its own per-edge class tag, source_primitives between distinct lens classes contain ZERO cross-references. Predict `(1 polygon + N lenses + (1 + N) circles)` shapes for an inscribed polygon-on-C0 + N spatially-disjoint lenses each anchored to C0.

**Why:** qiyas#132 Tick 72 (2026-05-27) authored `square-with-two-lenses-shared-circle.bkr.tmpl`. Construction: C0 r=100 ÷4 (inscribed square via `polygon [C0.cpt0 C0.cpt1 C0.cpt2 C0.cpt3]`), CL_a=(90,90) r=30 NE quadrant, CL_b=(90,-90) r=30 SE quadrant, CL_a/CL_b distance 180 >> r_a+r_b=60 (spatially disjoint circles, NOT mutually intersecting). Two `intersect` + two pairs of `connect arc` declarations with DISTINCT per-edge class tags `.lens_a` / `.lens_b`. Predicted 6 shapes (1 square + 2 lenses + 3 circles); ACTUAL: 6 shapes — square (vertex_count=4, has_arcs=false, .square), lens_a (vertex_count=2, has_arcs=true, .lens_a, source_primitives=[`.lens_a×2, C0:arc:#0, C0:arc:#1, layer:0×2`]), lens_b (vertex_count=2, has_arcs=true, .lens_b, source_primitives=[`.lens_b×2, C0:arc:#2, C0:arc:#3, layer:0×2`]), 3 circles. Zero cross-references between lens_a and lens_b source_primitives — each lens's C0-arc indices are partitioned (#0/#1 vs #2/#3). Square stayed whole (no opportunistic propagation by either lens). Generalizes [[feedback_bikar_arc_enrollment_local_not_propagated]] from N=1 lens (Ticks 69/70/71) to N≥2 lenses on a shared C0; the local-arc-enrollment rule is per-`connect arc`-declaration, not per-circle.

**How to apply:** When authoring Tier 1 multi-lens compositions on a shared construction circle: (a) ensure each lens's CL_n is genuinely intersected with C0 (`|d - (r_C0 + r_CL_n)| < r_C0 + r_CL_n` AND `d > |r_C0 - r_CL_n|`); (b) ensure the lens CL_n circles are PAIRWISE disjoint (`d > r_CL_a + r_CL_b`) — this entry doesn't witness mutually-intersecting lens circles, that's a separate hazard class; (c) give each lens a DISTINCT per-edge class tag in `connect arc` (`.lens_a` vs `.lens_b`, not both `.lens`) — same-class lenses would trigger Tick 60 same-class union and emit a single merged shape with face_count=2; (d) skip global `classify .lens_X where sides == 2` rules — the per-edge tags already carry the class; classify-by-`sides==2` predicate would tag both 2-sided faces with both classes (Tick 9 polyclass trap); (e) verify no lens endpoint coincides with a polygon vertex (Tick 67); (f) predict `(1 polygon + N lenses + (1 + N) circles)` shape count — for N=2, that's 6 shapes, not 5 (arithmetic slip Tenet 4 lesson: 1+N+(1+N) = 2+2N, NOT (1+N)+(N+1)/2 — count circles inclusive of C0). Companion to [[feedback_bikar_arc_enrollment_local_not_propagated]] (Tick 69 single-lens), [[feedback_bikar_gt_emitter_unions_same_class_chord_faces]] (Tick 60 same-class union hazard if (c) is violated), [[feedback_bikar_face_walker_shared_edge_absorption_universal]] (Tick 25 conditional-arc-enrollment upstream).
