When authoring Tier 1 polygon+polygon shared-vertex fixtures, compute ALL pairwise edge-edge intersections between the two polygons at design time — not just the declared shared vertex. If any non-shared edge pair crosses interior-to-interior, bikar's face-walker WILL split both polygons at that crossing, producing 3+ sub-faces instead of the expected 2 (plus possibly an invisible "gap" face from carved-out interior regions). The polyclass trap (Tick 9) also bites: a `classify .name where sides==N` predicate matches EVERY same-sides face regardless of class-tag heterogeneity, so all sub-faces emit with polyclass `tag_a tag_b` class lists.

**Why:** qiyas#132 Tick 68 (2026-05-27) authored `scalene-pair-shared-intersect-vertex.bkr.tmpl` predicting 4 emitted shapes (2 scalene triangles + 2 circles). Construction: C0 origin r=100 ÷6, C1 center=(140,0) r=80 ÷6, `intersect XS C0 C1` → XS.cpt0=(82.86, 56). tri_a=[XS.cpt0, C0.cpt0=(100,0), C0.cpt5=(50,-86.6)], tri_b=[XS.cpt0, C1.cpt2=(100,69.28), C1.cpt3=(60,0)]. Render outcome: 5 shapes emitted, with the SVG showing 4 face indices (0,1,2,4) where face 2 is invisible (fill="none") 4-sided gap face from tri_a's carved-out region. Diagnosis: tri_a's edge XS→C0.cpt0 crosses tri_b's edge C1.cpt2→C1.cpt3 at (86.14, 45.27), AND tri_a's edge XS→C0.cpt5 crosses the SAME tri_b edge at (76.57, 28.70) — two crossings beyond the declared shared vertex. The face-walker correctly subdivided at every crossing. ALL emitted faces tagged polyclass `tri_a tri_b` (Tick 9 trap fired again). Template renamed FALSIFIED-* per Tenet 18.

**How to apply:** Before authoring any Tier 1 polygon+polygon shared-vertex fixture (especially with intersect-derived shared vertex, which makes vertex placement less constrained than divide-point coincidence): for each pair (edge_a from polygon_A, edge_b from polygon_B) where the pair does NOT share the declared shared vertex, run a 2D line-segment intersection test. If ANY pair returns an interior point, EITHER (a) move polygon vertices so the convex hulls touch only at the declared shared vertex (no overlap), (b) accept the richer topology and write structurally-heterogeneous classify predicates that distinguish the sub-faces by some attribute other than `sides==N` (e.g., centroid quadrant, distinct ring tags via DSL extension), or (c) preserve as FALSIFIED-* hazard witness. Generalizes prior hazards: Tick 9 (polyclass `sides==N` trap), Tick 67 ([[feedback_bikar_arc_through_polygon_vertex_splits_both]]), and ARC-VS-POLYGON vertex coincidences — this lesson adds the POLYGON-VS-POLYGON edge-crossing hazard, completing the family.
